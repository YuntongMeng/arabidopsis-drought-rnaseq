# Arabidopsis Drought RNA-seq Reanalysis

## Overview

This repository documents an in-progress independent reanalysis of publicly available RNA-seq data from *Arabidopsis thaliana* roots under drought stress.

The experimental design, sequencing data, and primary biological hypotheses originate from the original study by Fàbregas et al. (2018). This repository documents an independent computational reanalysis of those publicly available data rather than a newly generated experiment.

The original study investigated the role of the vascular-enriched brassinosteroid receptor BRL3 in drought tolerance by comparing wild-type (Col-0) and 35S:BRL3 plants under well-watered and drought conditions.

The purpose of this repository is to develop and document a reproducible RNA-seq analysis workflow from raw sequencing reads through quality control, alignment, gene-level quantification, differential expression analysis, and biological interpretation.

## Data Source

The sequencing data used in this project were generated by the authors of the original study and are publicly available through the NCBI Gene Expression Omnibus (GEO) and Sequence Read Archive (SRA).

- GEO accession: GSE119382
- SRA study: SRP159462
- Organism: *Arabidopsis thaliana*
- Tissue: root
- Sequencing platform: Illumina HiSeq 2000

Raw sequencing data and large intermediate files are not redistributed in this repository.

## Original Experimental Design

The original RNA-seq experiment used a genotype-by-condition factorial design comparing:

- wild-type (Col-0) and 35S:BRL3 plants;
- well-watered and drought conditions.

The original experimental design specified biological replicates for each genotype-condition combination.

The current GEO record contains 11 RNA-seq samples rather than a complete balanced 12-sample dataset. One planned 35S:BRL3 well-watered replicate is not present in the current public record. This imbalance will be documented explicitly and considered when the factorial analysis is performed.

## Current Dataset

Initial workflow development and quality-control assessment were performed using:

- SRA run: SRR7779222
- GEO sample: GSM3373995
- Sample: 35S:BRL3 drought, replicate 1
- Sequencing layout: single-end
- Read length: 50 bp
- Library preparation: TruSeq Stranded mRNA

This sample is currently being used to learn and validate individual upstream analysis steps before expanding the workflow to multiple samples.

## Reanalysis Strategy

The reanalysis will be conducted in two stages.

### Stage 1 — Wild-type drought response

The complete RNA-seq workflow will first be established using the wild-type well-watered and drought samples.

The primary comparison will be:

`WT drought vs WT well-watered`

This stage is intended to establish a reproducible analysis workflow and characterize the transcriptional response of wild-type *Arabidopsis* roots to drought.

### Stage 2 — Genotype × condition analysis

The analysis will then be extended to the genotype-by-condition design used in the original study, incorporating both wild-type and 35S:BRL3 samples under well-watered and drought conditions.

The reanalysis will examine:

- the transcriptional response of wild-type roots to drought;
- baseline transcriptional differences associated with BRL3 overexpression;
- transcriptional differences between genotypes under drought;
- whether the drought response differs between wild-type and 35S:BRL3 plants using a genotype × condition interaction model.

The biological hypotheses evaluated in this stage originate from the original study. The goal of this reanalysis is to independently reproduce, evaluate, and interpret the transcriptomic patterns reported in the original publication.

## Workflow

The planned analysis workflow is:

FASTQ → FastQC → MultiQC → reference genome preparation → HISAT2 alignment → SAM/BAM processing with samtools → gene-level quantification with featureCounts → count matrix → differential expression analysis with DESeq2 → visualization → functional interpretation

## Quality Control

Initial quality control of SRR7779222 was performed using FastQC v0.12.1 and summarized using MultiQC v1.35.

Key observations from the initial QC assessment include:

- 25.9 million sequencing reads
- 46% overall GC content
- High per-base sequence quality
- No substantial known adapter contamination detected by FastQC
- Elevated sequence duplication
- Positional sequence-composition bias near the 5' end of reads

The elevated duplication level is documented here as a QC observation rather than treated as an automatic criterion for read removal. In bulk RNA-seq data, sequence duplication may reflect both biological transcript abundance and technical amplification and therefore requires interpretation in the context of the library and downstream analysis.

FastQC and MultiQC HTML reports are stored in the `qc/` directory.

## Repository Structure

- `qc/` — FastQC and MultiQC quality-control reports
- `scripts/` — analysis scripts and commands
- `counts/` — gene-level count data
- `results/` — downstream analysis results

Raw FASTQ files, reference genome files, alignment files, and other large intermediate files are excluded from version control.
