# Arabidopsis Drought RNA-seq Reanalysis

## Overview

This repository documents an in-progress reanalysis of publicly available
RNA-seq data from *Arabidopsis thaliana* roots under drought stress.

The original study investigated the role of the vascular-enriched
brassinosteroid receptor BRL3 in drought tolerance by comparing wild-type
(Col-0) and 35S:BRL3 plants under well-watered and drought conditions.

The purpose of this repository is to reproduce and document an RNA-seq
analysis workflow from raw sequencing reads through quality control,
alignment, gene-level quantification, differential expression analysis,
and biological interpretation.

## Data Source

The sequencing data used in this project were generated by the authors of
the original study and are publicly available through the NCBI Gene
Expression Omnibus (GEO) and Sequence Read Archive (SRA).

- GEO accession: GSE119382
- SRA study: SRP159462
- Organism: *Arabidopsis thaliana*
- Tissue: root
- Sequencing platform: Illumina HiSeq 2000

Raw sequencing data and large intermediate files are not redistributed
in this repository.

## Current Dataset

Initial workflow development and quality-control assessment were performed
using:

- SRA run: SRR7779222
- GEO sample: GSM3373995
- Sample: 35S:BRL3 drought, replicate 1
- Sequencing layout: single-end
- Read length: 50 bp
- Library preparation: TruSeq Stranded mRNA

This sample is currently being used to develop and validate the analysis
workflow. Additional samples will be incorporated for comparative
expression analysis.

## Workflow

The planned analysis workflow is:

FASTQ
→ FastQC
→ MultiQC
→ HISAT2 alignment
→ SAM/BAM processing with samtools
→ gene-level quantification
→ differential expression analysis
→ functional interpretation

## Quality Control

Initial quality control of SRR7779222 was performed using FastQC v0.12.1
and summarized using MultiQC v1.35.

Key observations from the initial QC assessment include:

- 25.9 million sequencing reads
- 46% overall GC content
- High per-base sequence quality
- No substantial known adapter contamination detected by FastQC
- Elevated sequence duplication
- Positional sequence-composition bias near the 5' end of reads

The elevated duplication level is documented here as a QC observation
rather than treated as an automatic criterion for read removal. In bulk
RNA-seq data, sequence duplication may reflect both biological transcript
abundance and technical amplification and therefore requires interpretation
in the context of the library and downstream analysis.

FastQC and MultiQC HTML reports are stored in the `qc/` directory.

## Repository Structure

- `qc/` — FastQC and MultiQC quality-control reports
- `scripts/` — analysis scripts and commands
- `counts/` — gene-level count data
- `results/` — downstream analysis results

Raw FASTQ files, reference genome files, alignment files, and other large
intermediate files are excluded from version control.
